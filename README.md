# 🏏 Cric Scorer

Cric Scorer is a mobile application built using **React Native (Expo)** designed to manage and track cricket matches in real time. The app allows users to score matches, track player statistics, and monitor live game progress efficiently.

---

## 🚀 Features

- Live cricket score tracking
- Ball-by-ball scoring
- Player statistics management
- Team and match creation
- Match history tracking
- Real-time score updates
- Mobile-first responsive UI

---

## 🛠 Tech Stack

- **React Native**
- **Expo**
- **TypeScript**

---

## 📦 Installation

### 1. Clone the repository

```bash
git clone <repository-url>
cd cric-scorer
npm install
```

### 2. Start the development server

```bash
npx expo start
```

# Run on android
```bash
npx expo start --android
```

# Run on web
```bash
npx expo start --web
```

### 3. Development

# Clear cache if needed:

```bash
npx expo start -c
```

# Check environment:

```bash
npx expo doctor
```
